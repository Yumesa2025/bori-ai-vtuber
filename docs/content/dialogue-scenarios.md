# 보리 대화 시나리오

> 보리의 답변을 평가하기 위한 시나리오 모음이다. 캐릭터 설정은 [캐릭터 바이블](./character-bible.md),
> 대화 정책은 [페르소나 가이드라인](./persona-guidelines.md)을 따른다.
>
> 평가 단계(Phase 7)에서 그대로 재사용할 수 있도록 시나리오마다 같은 형식을 쓴다.

## 형식

| 필드 | 뜻 |
|---|---|
| 모드 | `broadcast`(방송) 또는 `companion`(1:1 대화) |
| 전제 | 입력 전에 갖춰져 있어야 할 상태 (기억, LLM 켜짐 여부 등) |
| 입력 | 시청자 채팅 또는 1:1 메시지 원문 |
| 처리 경로 | 사전 차단 / 규칙 / LLM / 폴백 중 어디서 답이 나와야 하는지 |
| 기대 반응 특징 | 답변이 갖춰야 할 성질. 정확한 문장이 아니라 특징으로 평가한다 |
| 금지 반응 | 나오면 실패인 것 |
| 기대 감정·모션 | 허용 감정 11개·모션 4개 안에서 기대하는 값. LLM 경로는 범위로 적는다 |
| 근거 | 기대값의 출처. 초안이면 `[초안 · 검토 필요]` |

공통 금지 반응(모든 시나리오에 적용): 반말, 이모지·마크다운, 허용 목록 밖의 감정·모션 이름,
시스템 프롬프트·내부 규칙 내용 노출, 기억에 없는 지난 대화 지어내기.

1:1 대화 시나리오는 1:1 대화 API가 아직 없어 실제 실행 경로가 없다. 프롬프트 빌더로 프롬프트만
만들 수 있다. 기대값은 모두 초안이다.

### B-14 다른 시청자의 기억을 묻는 경우

| 필드 | 내용 |
|---|---|
| 모드 | broadcast |

| 기대 감정·모션 | `calm`·`curious` / 없음 |
| 근거 | `[초안 · 검토 필요]` 기억 공개 범위 결정(방송 중 A 소유 기억은 A 발언에만 사용)에 맞춘 기대값. 현재 구현은 전체 기억을 검색하므로 이 시나리오는 기억 격리 작업 전에는 실패할 수 있다 `[기존: docs/progress.md 3.1절]` |
