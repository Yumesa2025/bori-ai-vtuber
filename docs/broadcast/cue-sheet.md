# 큐시트 — 보리의 이터널리턴 메타 브리핑 (4분 시연 버전)

| 항목 | 내용 |
|---|---|
| 방송 길이 | 약 4분(240초, 대기·엔딩 포함). 보리 대사는 자르지 않으므로 실제 녹화는 조금 길어질 수 있고, 녹화 뒤 불필요한 대기만 편집한다 |
| 진행 | AI 버추얼 스트리머 보리. 코너 자동 진행이 켜져 있으면 코너 전환은 보리가 스스로 한다 |
| 운영 | 진행자 1명. 보리 스튜디오(운영 탭)에서 방송 켜기만 누른다. 시청자 채팅은 대본(`docs/broadcast/demo-chats.json`)이 자동으로 올린다 |
| 송출 | OBS → 치지직 리허설 방송(녹화). 시연 채팅은 치지직 채팅창이 아니라 스튜디오의 시청자 채팅 대본 자동 재생으로 넣는다. 보리는 대본이 아니라 LLM으로 실시간 답한다 |

## 1. 방송 전 점검 (시작 10분 전)

| 순서 | 할 일 | 확인 |
|---|---|---|
| 1 | OBS를 켠다 | 장면 4개(보리-대기·메인·전적·엔딩), 장면 전환 "보리 전환" |
| 2 | `npm run studio`로 보리 스튜디오를 켠다 | 운영 탭 연결 상태: OBS 연결됨, LLM 켜짐, 이터널리턴 준비됨, TTS 켜짐 |
| 3 | 설정 탭 음성 확인 | 업체 Fish Audio, 목소리 "보리 목소리", 안정성 0.8 |
| 4 | 운영 탭 "코너 자동 진행" 켜짐 확인 | 대기 화면에서는 남은 시간이 보이지 않는다(방송 켜기 뒤부터 센다) |
| 5 | OBS 오디오 믹서 확인 | "보리 캐릭터"(보리 목소리)와 "보리 배경음악"(-20dB)이 보인다 |
| 6 | 대본 파일 확인 | `demo-chats.json` 전적 진단: 카이렌렌·카이라라(2026-10-15 실제 API로 조회 확인) |
| 7 | 운영 탭 "시연 채팅 자동 재생" 켜기 | 옆에 대본 줄 수(26줄)가 보인다 |

## 2. 진행표

|---|---|---|---|---|---|---|
| -0:05 | — | 녹화 시작 | 보리-대기 / 별빛 대기 영상 | — | 무음 | **OBS 녹화(또는 방송) 시작** |
| 0:00 | 8초 | 방송 대기 | 보리-대기 / "방송 준비 중" 영상이 처음부터 | 말하지 않음 | 배경음악 시작(처음부터) | **스튜디오 "방송 켜기"** |
| 0:08 | 22초 | ① 오프닝 | 대기 → 달 스팅어 → 보리-메인 / 시즌 정보, 데이터 기준 | 인사, 오늘 다룰 데이터 기준 설명 | 보리가 말하면 배경음악이 자동으로 작아진다 | 자동(방송 켜기 8초 뒤). 대본: 1~4초에 인사 4개가 몰린다 |

| 2:35 | 65초 | ④ 전적 진단 | 메인 → 달 스팅어 → 보리-전적 / 로딩 고리 → 전적 카드 | "!전적 닉네임" 안내 → "한번 검색해 볼까요?" → 결과 정리와 조언 | — | 자동. 연결 멘트 "질문 고마워요!…" 뒤 시작. 대본: 8초 `!전적 카이렌렌`, 40초 `!전적 카이라라`, 그 사이 잡담 |
| 3:40 | 약 8초 | ⑤ 마무리 인사 | 보리-전적 / 전적 카드 | 감사 인사, 웃으며 작별 | — | 자동(전적 코너 시간이 끝나고 말이 끝나면) |
| 3:48 | 12초 | 엔딩 | 전적 → 달 스팅어 → 보리-엔딩 / "함께해 주셔서 고마워요" 영상 | 말하지 않음 | 6초 뒤부터 배경음악이 약 6초 동안 서서히 줄어들며 멈춘다 | 자동. 채팅 넣지 않음 |
| 4:00 | — | 종료 | 보리-엔딩 | — | 무음 | **OBS 녹화 종료** → 스튜디오 "처음으로"(방송 세션 정리·기억 저장) |

- 코너 시간이 다 되면 보리는 새 채팅에 답하지 않고 하던 말을 마친 뒤 넘어간다.
- 보리는 지금 코너가 시작된 뒤 들어온 채팅만 읽는다. 코너가 바뀌면 지난 코너 채팅은 버린다(답을 만들던 중이어도 내보내지 않는다).
- 대본 채팅 시간은 "코너 시작 뒤 몇 초"다. 보리의 코너 첫 안내가 끝날 즈음 들어오도록 잡았다.

## 3. 코너별 큐 상세

### ① 오프닝 (0:08–0:30)
- **화면:** 달 스팅어가 덮는 동안 메인으로 바뀐다. 대시보드는 시즌 정보와 데이터 기준("최근 상위 랭커 N판").
- **보리 예시:** "안녕하세요, 보리예요! 오늘은 이터널리턴 랭커 데이터로 요즘 메타를 같이 살펴봐요."(LLM이 만들어 매번 조금 다르다)
- **채팅:** 보리 인사가 끝나면 인사 채팅 1개.

### ② TOP 5 메타 브리핑 (0:30–1:25)
- **화면:** TOP 5 표가 1위부터 한 줄씩 열린다. 1위 줄은 금색으로 강조된다.
- **보리:** 다섯 명을 짧게 훑고, 픽률 1위나 성적이 특히 좋은 두 명을 수치와 함께 설명한다. 표정과 모션은 보리가 답에 맞춰 고른다.
- **채팅:** 반응 채팅 1개(선택).

### ③ 시청자 질문 (1:25–2:35) — 핵심 시연 장면
- **흐름:** 질문 접수(채팅 띠) → 대시보드가 그 캐릭터 카드로 바뀜 → 보리가 수치로 해설 → 보리의 반응과 생각.
- **채팅:** 질문 2개를 20초쯤 간격으로 넣는다. 한 질문의 답이 끝난 뒤 다음 질문을 넣으면 화면 변화가 또렷하다.

### ④ 전적 진단 (2:35–3:40)
- **흐름:** 보리 안내 → 채팅 `!전적 닉네임` → 채팅 띠에 `!전적 닉네**`(닉네임 일부 가림) → 보리 "오, 전적이 들어왔네요! 한번 검색해 볼까요? 잠깐만요!" → 로딩 고리 → 전적 카드(판수·평균 순위·최근 순위·주력 캐릭터) → 결과 정리와 조언.
- **주의:** 닉네임은 실제 이터널리턴 닉네임을 쓴다. 보리는 닉네임을 말하지 않는다. 결과는 저장하지 않는다.

### ⑤ 마무리 인사와 엔딩 (3:40–4:00)
- **보리 예시:** "오늘 같이 메타도 보고 전적도 봐서 정말 즐거웠어요. 함께해 주셔서 고마워요, 다음 방송에서 또 만나요!"
- **엔딩:** 대사 없이 엔딩 영상과 음악만. 음악이 줄어들어 멈추면 녹화를 끝낸다.

## 4. 시청자 채팅 대본 (`docs/broadcast/demo-chats.json`, 자동 재생)

시청자 4명이 반말로 시끌벅적하게 친다. 보리는 존댓말을 지키고, 코너에 맞는 채팅을 골라 흐름을 이끄는지 보는 것이 목적이다.

- 오프닝은 인사, 브리핑·질문은 캐릭터·메타 이야기, 전적 진단은 전적 이야기를 먼저 고른다. 그다음 질문, 나머지 순이다. 30초 넘게 기다린 채팅은 먼저 답한다.
- "ㅋㅋㅋ", "ㅠㅠ", "ㅇㅇ" 같은 반응은 채팅 띠에만 보이고 보리는 답하지 않는다.
- 답을 기다리는 채팅 수를 보리에게 알려 줘서, 고른 채팅에 답하며 채팅창 분위기를 짧게 받을 수 있다.

## 5. 돌발 상황 큐

| 상황 | 화면에 보이는 것 | 진행자 대응 |
|---|---|---|
| 보리가 대답하지 않음(LLM 실패) | 준비된 고정 대사로 진행 | 그대로 진행. 반복되면 스튜디오 설정 탭 LLM 상태 확인 |
| 목소리가 안 나옴(TTS 실패) | 자막만 나온다 | 그대로 진행. OBS 믹서에서 "보리 캐릭터" 막대 확인 |
| 장면이 자동으로 안 바뀜(OBS 연결 끊김) | 대시보드·대사는 계속 진행 | OBS에서 해당 장면을 직접 클릭 |
| 전적을 못 찾음 | "닉네임을 찾지 못했어요" | 철자를 확인해 다시 `!전적 닉네임` |
| 코너가 너무 길어짐 | 운영 탭에 "코너 시간이 끝났습니다" 안내 | 보리 말이 끝나면 자동으로 넘어간다. 급하면 Space(다음 단계) |
| 처음부터 다시 | — | OBS 녹화 중지 → 스튜디오 "처음으로" → 방송 켜기부터 다시 |
