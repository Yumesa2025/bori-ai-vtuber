# 방송 기획안 — 보리의 이터널리턴 메타 브리핑

| 항목 | 내용 |
|---|---|
| 방송명 | 보리의 이터널리턴 메타 브리핑 |
| 진행 | AI 버추얼 스트리머 보리(Live2D 캐릭터, LLM 대사, Fish Audio 음성) |
| 플랫폼 | 치지직 라이브(OBS 송출), 녹화본으로 시연 영상 제작 |
| 길이 | 약 4분(240초, 대기와 엔딩 포함) |
| 형식 | 실제 게임 데이터로 답하는 시청자 참여형 정보 방송 |

## 1. 콘텐츠 목표

1. **실제 데이터로 말하는 AI 진행자.** 이터널리턴 공식 API로 모은 최근 상위 랭커 경기 집계(픽률·평균 순위·1등 비율)만 근거로 말한다. 화면 카드와 보리의 말에 같은 수치가 나오고, 데이터 기준("최근 상위 랭커 N판")을 함께 보여 준다.
2. **수치를 읽는 데서 그치지 않고 의견을 붙인다.** "많이 고르고 성적도 좋아서 믿고 고르는 캐릭터 같아요"처럼 수치에서 보이는 보리의 생각을 한마디 더한다. 데이터에 없는 스킬·패치 이야기는 지어내지 않는다.
3. **시청자가 방송을 움직인다.** 채팅 한 줄이 캐릭터 카드와 전적 카드로 바로 화면에 나타나, 시청자가 자기 채팅의 결과를 눈으로 확인한다.
4. **사람 없이도 끊기지 않는 진행.** 코너마다 시간을 두고, 시간이 되면 보리가 하던 말을 마친 뒤 스스로 다음 코너로 넘어간다. 진행자는 언제든 직접 넘기거나 되돌릴 수 있다.

## 2. 시청자 참여 구조

| 참여 방법 | 시청자 행동 | 방송의 반응 |
|---|---|---|
| 캐릭터 질문 | 질문 코너에서 "재키 어때?"처럼 채팅 | 대시보드에 그 캐릭터 카드(픽률·평균 순위·1등 비율)가 뜨고, 보리가 수치와 생각을 말한다. 비슷한 이름이면 후보를 보여 준다 |
| 메타 질문 | "요즘 1티어 뭐야?" | 랭커가 많이 고른 상위 캐릭터를 근거로 "이번 데이터 기준"이라고 밝히며 답한다 |
| 전적 진단 | 전적 코너에서 `!전적 닉네임` | 채팅 띠에 닉네임을 가린 명령이 뜨고, 보리가 "한번 검색해 볼까요?" 하는 동안 조회해 전적 카드(판수·평균 순위·최근 순위·주력 캐릭터)와 분석·조언을 보여 준다 |
| 자유 채팅 | 인사, 잡담 | 두 문장 이내로 반응한다. 코너와 맞지 않는 질문에는 짧게 답하고 지금 코너로 안내한다 |
| 조용할 때 | — | 보리가 코너에 맞는 혼잣말로 참여를 이끈다(예: 전적 코너에서 "닉네임을 적어 주시면 바로 봐 드릴게요") |

- **표시 방식:** 채팅은 화면 오른쪽 아래 띠에 최근 몇 줄만 보인다. 명령 채팅은 금색으로 구분한다.
- **닉네임 보호:** 시청자 닉네임은 화면과 보리 대사에 나오지 않는다. 전적 조회 닉네임은 일부를 가려 보이고, 조회 결과는 저장하지 않는다.
- **채팅 순서:** 질문 채팅을 먼저 고르되, 오래 기다린 채팅이 밀리지 않게 한다. 한 시청자는 대기열에 3개까지만 들어간다.

## 3. 방송 타임라인 — 4분 시연 버전

모든 코너를 같은 길이로 두지 않고 콘텐츠 특성에 따라 시간을 나눈다. 시청자 질문이 가장 중요한 시연 장면이라 가장 길게 둔다.

| 시간 | 코너 | 길이 | OBS 장면 | 화면 | 보리 | 시청자 참여 |
|---|---|---|---|---|---|---|
| 0:00~0:08 | 방송 대기 | 8초 | 보리-대기 | 별빛 "방송 준비 중" 영상, 배경음악 시작 | 말하지 않음 | 입장 채팅 |
| 0:08~0:30 | ① 오프닝 | 22초 | 대기 → 메인(달 스팅어) | 시즌 정보, 데이터 기준 | 인사하고 오늘 다룰 데이터 기준 설명 | 인사 채팅 |
| 0:30~1:25 | ② TOP 5 메타 브리핑 | 55초 | 메인 | TOP 5가 한 줄씩 열림 | TOP 5를 훑고 눈에 띄는 두 명을 수치로 자세히 해설, 표정·리액션 | 반응 채팅 |
| 1:25~2:35 | ③ 시청자 질문 | 70초 | 메인 | 질문받은 캐릭터 카드 | 질문 접수 → 대시보드 변화 → 데이터 해설 → 보리의 반응 | 캐릭터·메타 질문 1~2개 |
| 2:35~3:40 | ④ 전적 진단 | 65초 | 메인 → 전적(달 스팅어) | 로딩 애니메이션 → 전적 카드(닉네임 일부 가림) | "검색해 볼까요?" → 결과 정리와 특징 분석, 조언 | `!전적 닉네임` 1개 |
| 3:40~3:48 | ⑤ 마무리 인사 | 8초 | 전적 | 전적 카드 | 감사 인사와 웃으며 작별 | — |
| 3:48~4:00 | 엔딩 화면 | 12초 | 전적 → 엔딩(달 스팅어) | "함께해 주셔서 고마워요" 영상 | 말하지 않음 | — |

## 4. 코너별 연출

- **대기와 오프닝(30초):** 별빛 로딩 화면에서 시작해 달 스팅어로 메인 방송에 들어간다. 보리가 인사하고 오늘 다룰 게임 데이터의 기준("최근 상위 랭커 N판")을 설명한다.
- **메타 브리핑(55초):** TOP 5를 순서대로 보여 주고, 눈에 띄는 캐릭터 두 명을 자세히 설명한다. 보리의 표정·시선·리액션을 함께 보여 준다.
- **시청자 질문(70초):** 질문 1~2개를 받아 캐릭터 데이터를 보여 준다. 질문 접수 → 대시보드 변화 → AI 해설 → 보리의 반응으로 이어지는, 가장 중요한 시연 장면이다.
- **전적 진단(65초):** `!전적 닉네임` 요청 하나를 받는다. 채팅 띠에 가린 닉네임으로 명령이 뜨고, 로딩 애니메이션 뒤 전적 결과와 데이터에서 보이는 특징을 분석한다.
- **마무리와 엔딩(20초):** 보리가 감사 인사를 하고 웃는 얼굴로 작별한다. 엔딩 전용 화면으로 넘어가 배경음악이 서서히 줄어들며 끝난다.

## 5. 진행 원칙

1. 코너마다 목표 시간을 두고, 시간이 되면 보리가 하던 말을 마친 뒤 연결 멘트를 하고 스스로 다음 코너로 넘어간다(코너 자동 진행). 대사를 급하게 자르지 않는다.
2. 마무리 인사는 메인 방송에서 하고, 엔딩 화면에서는 대사 없이 음악과 영상 연출만 남긴다.
3. 배경음악은 방송 대기부터 엔딩까지 장면이 바뀌어도 이어 흐르고, 보리가 말할 때는 자동으로 작아진다.
4. 장면이 바뀔 때는 달 스팅어가 화면을 덮는 동안 바뀐다. 오프닝~질문은 같은 장면이라 대시보드만 바뀐다.
5. 진행자는 보리 스튜디오에서 방송 켜기, 시청자 채팅 입력, 필요할 때 다음·이전·처음으로, 코너 자동 진행 켜기·끄기를 다룬다.
6. 실제 시연에서는 코너별 AI 응답 시간을 재고, 녹화 뒤 불필요한 대기만 편집해 약 4분으로 완성한다.
7. 포트폴리오에는 실제로 구현한 기능과, 시연 채팅을 치지직 채팅창이 아닌 보리 스튜디오의 로컬 시청자 채팅 입력(시청자 채팅 대본 자동 재생)으로 넣었다는 점을 명확히 적는다. 치지직에는 OBS 화면만 송출했다.
8. 보리는 지금 코너가 시작된 뒤 들어온 채팅만 읽는다. 시청자 채팅은 대본으로 코너 시간에 맞춰 들어오므로 지난 코너 채팅은 읽지 않는다.

## 6. 예상 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| LLM 응답 지연·실패 | 보리가 말을 못 함 | 단계별 준비 대사와 규칙 문장으로 대신 말하고 방송은 이어 간다. 실패는 스튜디오에만 보인다 |
| 음성 합성 실패·지연 | 소리 없음 | 6초 안에 오지 않으면 자막만으로 진행한다 |
| 목소리 톤이 합성마다 흔들림 | 캐릭터 일관성 저하 | 고정 목소리 모델("보리 목소리")과 높은 안정성(0.8)으로 무작위성을 줄인다 |
| 수치를 지어내거나 틀리게 말함 | 정보 방송 신뢰 하락 | 서버가 넣은 수치 줄만 근거로 쓰게 하고, 화면 카드와 같은 반올림을 쓴다. 데이터 없는 캐릭터는 "표본에 없다"고 말한다. 평가 시나리오로 검사한다 |
| "1티어" 같은 표현이 공식 평가로 오해됨 | 잘못된 정보 전달 | "이번 랭커 데이터 기준"임을 말과 화면에 함께 밝힌다 |
| 채팅이 없음 | 공백 | 코너별 혼잣말로 참여를 유도하고, 코너 시간이 되면 다음으로 넘어간다 |
| 채팅이 몰림 | 답이 밀림 | 대기열 상한, 시청자별 3개 상한, 오래된 채팅 만료로 최신 흐름을 유지한다 |
| 부적절·공격 채팅 | 방송 사고 | 위험 입력은 차단해 무반응하고, 프롬프트 주입 문장은 걸러 낸다 |
| 개인정보 노출 | 시청자 피해 | 닉네임을 화면·대사에 쓰지 않고, 전적 조회 닉네임은 가리며 결과를 저장하지 않는다 |
| 이터널리턴 API 제한(초당 1회)·장애 | 데이터 없음 | 메타 집계는 방송 전에 미리 모아 두고, 전적 조회 실패 시 "지금은 불러오지 못했어요"라고 안내한다 |
| OBS 연결 끊김 | 장면 자동 전환 안 됨 | 단계와 대사는 계속 진행하고, 진행자가 OBS에서 장면을 직접 바꾼다 |
| 시간 초과 | 방송이 길어짐 | 코너 자동 진행이 목표 시간에 맞춰 넘긴다(말은 자르지 않음). 녹화 뒤 불필요한 대기만 편집한다 |

## 7. 결정과 구현 기록 (2026-10-15 리허설 기준)

리허설을 하며 정한 것과 실제로 구현한 것을 모아 둔다. 이력서·포트폴리오를 쓸 때 근거로 쓴다. "미검증"은 실제 환경에서 아직 확인하지 않은 것이다.

### 7.1 방송 구성

| 결정 | 내용 |
|---|---|
| 콘텐츠 | 이터널리턴 공식 API 데이터로 하는 메타 브리핑 + 시청자 질문 + 전적 진단 |
| 길이 | 4분 시연 버전. 대기 8초 → 오프닝 22초 → 브리핑 55초 → 질문 70초 → 전적 65초 → 마무리 인사 약 8초 → 엔딩 12초 |
| 코너 자동 진행 | 코너마다 목표 시간을 두고, 시간이 되면 새 채팅 답을 멈추고 하던 말을 마친 뒤 연결 멘트 → 다음 코너. 대사는 자르지 않는다. 진행자가 언제든 직접 넘기거나 되돌릴 수 있다 |
| 방송 켜기 | 오프닝 앞 단계. 대기 영상과 배경음악이 처음부터 시작하고 8초 뒤 자동으로 오프닝 |
| 마무리 | 엔딩에서는 말하지 않는다. 마무리 인사는 전적 진단을 떠날 때 메인 방송에서 하고, 말이 끝난 뒤 엔딩으로 넘어간다 |
| 엔딩 | 엔딩 영상만. 6초 뒤 배경음악이 약 6초 동안 서서히 줄어들어 멈춘다 |
| 대기·엔딩 침묵 | 대기·엔딩 장면에서는 채팅 답·혼잣말을 하지 않는다 |

### 7.2 화면과 연출 (OBS)

- OBS 장면 4개(보리-대기·메인·전적·엔딩)를 서버가 OBS WebSocket(v5)으로 자동 전환한다. `npm run obs:setup` 한 번으로 장면·소스·전환·음악·필터를 만든다(기존 것은 지우지 않고 숨긴다).
- 레이어: 배경 영상 → 대시보드(브라우저 소스) → 보리 Live2D(브라우저 소스, 투명) → 채팅 띠 → 자막.
- 사용자가 만든 배경 영상 3개(대기·메인·엔딩)와 달 스팅어 전환 영상(VP9 알파, 2초)을 쓴다. 스팅어 전환 시점은 영상이 화면을 다 덮는 구간(0.53~1.23초)을 재서 1.0초로 정했다.
- 대시보드·채팅 패널을 메인 영상의 금테 틀 좌표(큰 틀 x 788–1860·y 36–625, 작은 틀 y 649–850)에 맞추고, 영상 위에서는 패널 자체 테두리·바탕을 지웠다.
- 캐릭터 영역을 틀 앞(788px)까지 넓혔다. 모델은 캔버스 높이에 맞춰 그려져 크기는 그대로이고 좌우 여유만 늘었다(처음엔 폭에 맞춰 커질 거라 보고 배율 보정을 넣었다가 실측으로 되돌림).
- 자막: 말하는 시간(음성 길이)에 맞춰 세 줄씩 넘긴다. 실제 글꼴·폭으로 재고 폭을 6% 좁게 잡아 화면에서 넘치지 않게 했다.
- 전적 검색 중에는 금색 로딩 고리와 "전적을 검색하고 있어요"를 보인다.
- 배경음악은 네 장면 공통 소스라 장면이 바뀌어도 이어지고(-20dB), 보리 목소리를 사이드체인으로 한 압축 필터가 보리가 말할 때 음악을 자동으로 낮춘다.

### 7.3 보리의 말

- 게임 질문에는 서버가 넣은 수치 줄만 근거로 말하고, 수치에서 보이는 보리의 생각을 "~같아요"로 붙인다. 데이터에 없는 스킬·패치·무기 특성은 지어내지 않는다(실모델이 무기 특성을 지어내 주 무기 줄을 프롬프트에서 뺐다).
- 각 캐릭터가 집계 전체에서 몇 번째인지(많이 고른 순서·평균 순위 순서)를 함께 넣어, "많이 고르지만 성적은 중간" 같은 의견의 근거로 쓴다.
- "여러분은 어떻게 생각하시나요?"처럼 시청자에게 의견을 묻는 문장은 규칙만으로 줄지 않아 서버가 방송 답에서 지운다.
- 지금 코너를 방송 상황에 알려 주고(채팅 답에만), 코너별 혼잣말을 둔다. 전적 진단 코너는 캐릭터 질문으로 다루지 않는다.
- 진행 대사(오프닝·브리핑·안내·전적 분석·마무리)는 단계 지시로 LLM이 만들고, 실패하면 준비한 고정 문장으로 대신한다.
- 리허설에서 고친 회귀: 코너 안내 줄이 전적 분석 대사에도 섞여 결과 정리 대신 안내만 되풀이했다 → 코너 안내는 채팅 답에만 넣는다.

### 7.4 시청자 채팅과 시연 방식

- 시연 채팅은 치지직 채팅창이 아니라 보리 스튜디오의 로컬 "시청자 채팅" 입력으로 넣는다. 치지직에는 OBS 화면만 송출해 리허설 방송으로 녹화한다. 치지직 Open API 채팅 수신은 구현돼 있지만 시연에는 쓰지 않는다.
- 포트폴리오 시연은 **시청자 채팅 대본**(`docs/broadcast/demo-chats.json`)으로 한다. 코너마다 "코너 시작 몇 초 뒤, 닉네임, 채팅"을 적어 두고 스튜디오 "시연 채팅 자동 재생"을 켜면 서버가 그 시간에 채팅을 올린다. 보리는 대본이 아니라 LLM으로 실시간 답한다. 보리가 제대로 하는지, 고장 나는지 확인하는 용도다.
- 보리는 지금 코너가 시작된 뒤 들어온 채팅만 읽는다. 코너가 바뀌면 지난 코너 채팅은 대기열에서 버리고, 답을 만들던 중이어도 내보내지 않는다.
- `!전적 닉네임`: 채팅 띠에 닉네임을 가린 명령(`!전적 테스**`)이 뜨고, 보리가 "한번 검색해 볼까요?" 하는 동안 조회해, 말이 끝난 뒤 전적 카드와 분석·조언을 보여 준다. 닉네임은 화면·대사에 쓰지 않고 결과는 저장하지 않는다.
- 시청자 닉네임은 화면에 나오지 않는다. 한 시청자는 대기열에 3개까지, 질문 채팅을 먼저 고르되 오래 기다린 채팅이 밀리지 않게 한다.

### 7.5 음성

- TTS 업체를 OpenAI·ElevenLabs에 이어 Fish Audio로 넓혔다(`POST /v1/tts`, 모델 s2.1-pro, mp3). 키는 `.env`의 `FISH_API_KEY`.
- 공개 목소리(샘플 1개 빠른 복제)는 합성마다 음색이 흔들렸다. 안정성 값(→ temperature·top_p)을 만들고, 사용자가 고른 합성 샘플로 Fish 계정에 비공개 목소리 "보리 목소리"를 만들어 고정했다(안정성 0.8).
- 방송 음성은 6초 안에 오지 않으면 자막만으로 진행한다.

### 7.6 데이터

- 이터널리턴 공식 API(개인 키 초당 1회)로 최근 상위 랭커 경기를 모아 캐릭터별 픽률·평균 순위·1등 비율을 집계해 두고, 방송에서는 그 집계만 쓴다. 데이터 기준("최근 상위 랭커 N판")을 화면과 말에 함께 밝힌다.
- API 시즌 이름은 얼리 액세스 시즌부터 이어 센다(Season21). 게임 표기(정식 시즌 12)에 맞춰 9를 빼서 보인다. 예전 집계 파일도 읽을 때 바꾼다.

### 7.7 운영 도구 (보리 스튜디오, Electron)

- 운영 탭: 방송 켜기, 다음·이전·처음으로(Space), 코너 자동 진행 켜기·끄기와 코너 남은 시간, 시연 채팅 자동 재생, 시청자 채팅(닉네임 칸), OBS·LLM·TTS·이터널리턴 연결 상태, 데이터 갱신.
- 설정 탭: LLM, 음성(업체·목소리 ID·속도·안정성), 기억, 사용량·비용. 1:1 대화 탭도 같은 앱에 있다.

### 7.8 검증과 남은 것

- 자동 검사: 단위 833건, 실제 서버를 띄우는 통합 시나리오(방송 진행·OBS 가짜 서버·치지직 가짜 서버·ER 가짜 서버 포함), 대화 평가 시나리오 57건 정적 평가. GitHub Actions(ubuntu·windows)에서 돌린다.
- 실제 환경에서 확인한 것: 실제 OBS 장면·소스·스팅어 재생(전환 약 2.26초), 배경 영상 배치, 캐릭터 영역, Fish Audio 실제 합성, 시즌 표기.
- 미검증: 4분 전체를 실제로 돌려 잰 시간, 배경음악 볼륨·덕킹 체감, 실모델에서 의견 묻기 문장 제거 뒤 말투, 시연 채팅 대본으로 처음부터 끝까지 돈 결과.
