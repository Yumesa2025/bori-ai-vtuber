# 방송 기획안 — 보리의 이터널리턴 메타 브리핑

| 항목 | 내용 |
|---|---|
| 방송명 | 보리의 이터널리턴 메타 브리핑 |
| 진행 | AI 버추얼 스트리머 보리(Live2D 캐릭터, LLM 대사, Fish Audio 음성) |
| 플랫폼 | 치지직 라이브(OBS 송출), 녹화본으로 시연 영상 제작 |
| 길이 | 약 4분 30초(코너 4개 + 엔딩) |
| 형식 | 실제 게임 데이터로 답하는 시청자 참여형 정보 방송 |

## 1. 콘텐츠 목표

1. **실제 데이터로 말하는 AI 진행자.** 이터널리턴 공식 API로 모은 최근 상위 랭커 경기 집계(픽률·평균 순위·1등 비율)만 근거로 말한다. 화면 카드와 보리의 말에 같은 수치가 나오고, 데이터 기준("최근 상위 랭커 N판")을 함께 보여 준다.
2. **수치를 읽는 데서 그치지 않고 의견을 붙인다.** "많이 고르고 성적도 좋아서 믿고 고르는 캐릭터 같아요"처럼 수치에서 보이는 보리의 생각을 한마디 더한다. 데이터에 없는 스킬·패치 이야기는 지어내지 않는다.
3. **시청자가 방송을 움직인다.** 채팅 한 줄이 캐릭터 카드와 전적 카드로 바로 화면에 나타나, 시청자가 자기 채팅의 결과를 눈으로 확인한다.
4. **사람 없이도 끊기지 않는 진행.** 코너마다 시간을 두고, 시간이 되면 보리가 하던 말을 마친 뒤 스스로 다음 코너로 넘어간다. 진행자는 언제든 직접 넘기거나 되돌릴 수 있다.

## 2. 시청자 참여 구조

| 참여 방법 | 시청자 행동 | 방송의 반응 |
|---|---|---|
| 캐릭터 질문 | 질문 코너에서 "재키 어때?"처럼 채팅 | 대시보드에 그 캐릭터 카드(픽률·평균 순위·1등 비율)가 뜨고, 보리가 수치와 생각을 말한다. 비슷한 이름이면 후보를 보여 준다 |
| 메타 질문 | "요즘 1티어 뭐야?" | 랭커가 많이 고른 상위 캐릭터를 근거로 "이번 데이터 기준"이라고 밝히며 답한다 |
| 전적 진단 | 전적 코너에서 `!전적 닉네임` | 채팅 띠에 닉네임을 가린 명령이 뜨고, 보리가 "한번 검색해 볼까요?" 하는 동안 조회해 전적 카드(판수·평균 순위·최근 순위·주력 캐릭터)와 분석·조언을 보여 준다 |
| 자유 채팅 | 인사, 잡담 | 두 문장 이내로 반응한다. 코너와 맞지 않는 질문에는 짧게 답하고 지금 코너로 안내한다 |
| 조용할 때 | — | 보리가 코너에 맞는 혼잣말로 참여를 이끈다(예: 전적 코너에서 "닉네임을 적어 주시면 바로 봐 드릴게요") |

- **표시 방식:** 채팅은 화면 오른쪽 아래 띠에 최근 몇 줄만 보인다. 명령 채팅은 금색으로 구분한다.
- **닉네임 보호:** 시청자 닉네임은 화면과 보리 대사에 나오지 않는다. 전적 조회 닉네임은 일부를 가려 보이고, 조회 결과는 저장하지 않는다.
- **채팅 순서:** 질문 채팅을 먼저 고르되, 오래 기다린 채팅이 밀리지 않게 한다. 한 시청자는 대기열에 3개까지만 들어간다.

## 3. 방송 타임라인

| 시간 | 코너 | OBS 장면 | 화면 | 보리 | 시청자 참여 |
|---|---|---|---|---|---|
| 방송 전 | 대기 | 보리-대기 | "방송 준비 중" 영상 | 말하지 않음 | — |
| 0:00~0:30 | ① 오프닝 | 대기 → 메인(달 전환) | 시즌 정보, 데이터 기준 | 인사, 오늘 할 것 소개 | 인사 채팅 |
| 0:30~1:30 | ② 메타 브리핑 | 메인 | TOP 5가 한 줄씩 열림 | 순위 소개와 눈에 띄는 점에 대한 생각 | 반응 채팅 |
| 1:30~3:00 | ③ 질문 코너 | 메인 | 질문받은 캐릭터 카드 | 데이터로 답하고 의견 한마디 | 캐릭터·메타 질문 2~3개 |
| 3:00~4:00 | ④ 전적 진단 | 메인 → 전적(달 전환) | 전적 카드(닉네임 일부 가림) | "검색해 볼까요?" → 분석과 조언 | `!전적 닉네임` |
| 4:00~4:30 | ⑤ 엔딩 | 전적 → 엔딩(달 전환) | "함께해 주셔서 고마워요" 영상 | 말하지 않음 | — |

- **코너 넘김:** 코너 시간이 다 되면 새 채팅 답을 멈추고, 하던 말을 마친 뒤 연결 멘트("질문 고마워요! 시간이 다 돼서 다음 코너로 넘어갈게요.")를 하고 넘어간다.
- **장면 전환:** 장면이 바뀔 때는 스팅어(달 애니메이션)가 화면을 덮는 동안 바뀐다. 오프닝~질문은 같은 장면이라 대시보드만 바뀐다.
- **운영:** 진행자는 보리 스튜디오에서 Space(다음 단계)·이전·처음으로, 시청자 채팅 입력, 코너 자동 진행 켜기·끄기를 다룬다.

## 4. 예상 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| LLM 응답 지연·실패 | 보리가 말을 못 함 | 단계별 준비 대사와 규칙 문장으로 대신 말하고 방송은 이어 간다. 실패는 스튜디오에만 보인다 |
| 음성 합성 실패·지연 | 소리 없음 | 6초 안에 오지 않으면 자막만으로 진행한다 |
| 목소리 톤이 합성마다 흔들림 | 캐릭터 일관성 저하 | 고정 목소리 모델("보리 목소리")과 높은 안정성(0.8)으로 무작위성을 줄인다 |
| 수치를 지어내거나 틀리게 말함 | 정보 방송 신뢰 하락 | 서버가 넣은 수치 줄만 근거로 쓰게 하고, 화면 카드와 같은 반올림을 쓴다. 데이터 없는 캐릭터는 "표본에 없다"고 말한다. 평가 시나리오로 검사한다 |
| "1티어" 같은 표현이 공식 평가로 오해됨 | 잘못된 정보 전달 | "이번 랭커 데이터 기준"임을 말과 화면에 함께 밝힌다 |
| 채팅이 없음 | 공백 | 코너별 혼잣말로 참여를 유도하고, 코너 시간이 되면 다음으로 넘어간다 |
| 채팅이 몰림 | 답이 밀림 | 대기열 상한, 시청자별 3개 상한, 오래된 채팅 만료로 최신 흐름을 유지한다 |
| 부적절·공격 채팅 | 방송 사고 | 위험 입력은 차단해 무반응하고, 프롬프트 주입 문장은 걸러 낸다 |
| 개인정보 노출 | 시청자 피해 | 닉네임을 화면·대사에 쓰지 않고, 전적 조회 닉네임은 가리며 결과를 저장하지 않는다 |
| 이터널리턴 API 제한(초당 1회)·장애 | 데이터 없음 | 메타 집계는 방송 전에 미리 모아 두고, 전적 조회 실패 시 "지금은 불러오지 못했어요"라고 안내한다 |
| OBS 연결 끊김 | 장면 자동 전환 안 됨 | 단계와 대사는 계속 진행하고, 진행자가 OBS에서 장면을 직접 바꾼다 |
| 시간 초과 | 방송이 길어짐 | 코너 자동 진행이 시간표대로 넘긴다. 진행자가 직접 넘길 수도 있다 |
